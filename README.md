# Maquillaje Ideal

Sistema web desarrollado con FastAPI y PostgreSQL para la gestión de productos de maquillaje.

## Tecnologías

- FastAPI
- PostgreSQL (Neon)
- HTML
- CSS
- JavaScript
- Render

## Funcionalidades

- CRUD de productos
- CRUD de categorías
- CRUD de tipos de piel
- Recomendación de productos
- Búsqueda de productos
- Dashboard estadístico

## Base de Datos

La base de datos está alojada en Neon PostgreSQL.
